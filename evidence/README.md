# Curated evidence

This directory contains compact, reviewable exports. Raw private receipts, models, binaries, CUDA
profiler captures, and session histories are intentionally excluded.

- [R608](r608/README.md): current full 4,096-prefix/128-output native same-weight DFlash2 authority.
- [R610–R612 diagnostics](diagnostics/r610-r612-summary.csv): bounded eight-output screens.

The original receipt names and cryptographic identities are retained. Numeric exports are copied or
derived from the identified receipt without relabeling the workload contract. Reproduction also
requires the matching model manifests and hardware/software environment.
